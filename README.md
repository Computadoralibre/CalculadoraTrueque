Calculadora Trueque:

Las personas necesitan de una herramienta, para valorar los trueques. Se puede hacer un programa para computadoras
de amplio uso, pero por el momento estan las hojas de calculo que muestran el modelo de datos y el concepto que se
usa para valorar las mercancias y recomendaciones sociales.

Tasas de cambio o tipos de cambio, según la persona pero en resumen es el historial de la relación de intercambio
que se tiene entre las diferentes mercancías. Desde una perspectiva de un agente economico aislado es la información
que el agente puede acumular. Tratar de dar servicio con este modelo para muchos usuarios tendrá que ser servido en 
una cola de mensajes, ya que tratar de dar servicio simultaneamente va a ver conflicto en la escritura.

Para completar se puede implementar el sistema de recomendación como parte del programa, habría que utilizar 
PGP("Pretty Good Privacy" de sus siglas en ingles) para firmar las recomendaciones que se pasan los usuarios. 
Ej: de A a B firmado por A. 

El objetivo es mantener los dos aspectos que usan las personas para valorar su que hacer y praxis. Uso una
ecuación de descripción del bienestar como sigue:

Bienestar = Valor Mercancias * Seno Ø + Valor Social * Coseno Ø

0 <= Ø <= 90°

La coordinación lógica de estas actividades mantienen la relación de que el resultado de su bienestar
sera probabilisticamente cercano para cada aspecto que se tome encuenta en la actividad en la misma
relación de la "Desigualdad de Chebichev": 

Para cualquier variable aleatoria X con media M y varianza D^2.
P(|X - M| >= c*D) <= 1/c^2

Que se lee de la siguiente manera, la probabilidad de que una variable aleatoria (Bienestar) 
difiera de su media al menos en c desviaciones estándar, es menor o igual que 1/c^2. Por ejemplo, emplear c=2 implica
que la probabilidad de que cualquier variable aleatoria difiera de su media al menos por dos desviaciones estándar, no es
mayor que un 1/4.

Lo que planteo es que el bienestar es probabilisticamente improbable que difiera demasiado sin importar si les damos
mas importancia a cualquiera de los dos valores(Mercancias y Sociales).
