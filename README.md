Calculadora Trueque:

Las personas necesitan de una herramienta, para valorar los trueques. Se puede hacer un programa para computadoras
de amplio uso, pero por el momento estan las hojas de calculo que muestran el modelo de datos y el concepto que se
usa para valorar las mercancias.

Tasas de cambio o tipos de cambio, según la persona pero en resumen es el historial de la relación de intercambio
que se tiene entre las diferentes mercancías. Desde una perspectiva de un agente economico aislado es la información
que el agente puede acumular. Tratar de dar servicio con este modelo tendrá que ser servido en una cola de mensajes, ya que tratar de dar servicio simultaneamente va a ver conflicto en la escritura.

Para completar se puede implementar el sistema de recomendación como parte del programa, habría que utilizar PGP para firmar las recomendaciones que se pasan los usuarios. Ej: de A a B firmado por A.
